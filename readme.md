## Sobre o projeto

O **CardioIA** é o projeto PBL deste ano: uma plataforma digital que simula o ecossistema de uma cardiologia moderna. Ao longo de 7 fases, ele integra dados clínicos, Machine Learning, Visão Computacional, IoT e agentes inteligentes para apoiar triagem, diagnóstico, monitoramento, assistência remota e previsões médicas.
